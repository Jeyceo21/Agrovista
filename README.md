# 📖 Overview

AgroVista is an AI-powered smart agriculture platform designed to help farmers and agricultural organizations monitor crop conditions, soil health, weather parameters, and pest risks through an intuitive analytics dashboard.

The platform combines real-time environmental data, intelligent recommendations, and interactive visualizations to support precision farming and data-driven agricultural decision-making.

---

# 🎯 Problem Statement

Modern farming requires continuous monitoring of environmental conditions, crop health, and soil quality.

Traditional methods often rely on manual observations, making it difficult to identify risks early and optimize resource usage.

AgroVista addresses these challenges through a centralized AI-powered dashboard that provides actionable agricultural insights.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Jeyceo21/AgroVista.git
```

---

## Install Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## Install Backend

```bash
cd server

npm install

npm start
```
